## 3. Heading Structure

### Current State

**Critical Finding: No H1 tag detected in body sample.**

The visible body text renders as decorative/UI elements, chess symbols, and JavaScript-driven cart/modal content. The closest candidate for a headline — `"Promoting Chess One Piece at a Time"` — appears to be rendered as styled `<div>` or `<span>` elements based on the fragmented way it appears in the body text (`7 7 T H Promoting Chess One Piece at a Time R A N K`), suggesting it is either:

1. Broken into individual character `<span>` elements for animation purposes (common with GSAP), OR
2. Rendered as an image/canvas element

**Either way, Google cannot read it as an H1.**

| Element | Status | Issue |
|---------|--------|-------|
| H1 | ❌ Not detected | Missing or rendered as non-semantic element |
| H2 | ⚠️ Uncertain | "Collections", "Contact" likely nav labels, not content H2s |
| H3–H6 | ⚠️ Uncertain | No clear hierarchy visible in body text |
| Keyword in H1 | ❌ N/A | H1 absent |

### Analysis

The GSAP animation library (`gsap.min.js` + `ScrollTrigger.min.js`) is loading on this page. A common pattern with GSAP-animated text is to split words or characters into individual `<span>` elements for animation (`SplitText` plugin or manual splitting). When Google crawls the page, it sees:

```html
<span>7</span><span>T</span><span>H</span>...
```

...instead of a semantically meaningful heading. This is one of the most common SEO-damaging patterns in animation-heavy fashion brand sites.

### Recommendations

**🔴 HIGH PRIORITY:**

1. **Add a visible or screen-reader-accessible H1** that contains the primary keyword. If the animated text must remain, add a visually hidden H1 above it:

```html
<h1 class="visually-hidden">7th Rank — Premium Chess Streetwear &amp; Apparel</h1>
<!-- Your animated div/spans below -->
<div class="hero-animated-text" aria-hidden="true">
  <!-- GSAP split text animation here -->
</div>
```

The `.visually-hidden` CSS class (position: absolute; clip; overflow: hidden) is the industry-standard accessibility and SEO pattern for this use case.

2. **Map H2 tags to collection/product sections:**
```
H2: "First Move Collection"
  H3: "Stoic Line"
  H3: "Grain Line"
  H3: "Thin Ice (TI) Line"
  H3: "Pasture Line"
  H3: "Harmony Line"
H2: "Shop Chess Hoodies & Tees"
H2: "About 7th Rank"
```

3. **Ensure collection names include keywords.** "Stoic" and "Grain" are brand names — they need keyword-adjacent H3 context like: `<h3>Stoic — Chess Hoodie Collection</h3>`
